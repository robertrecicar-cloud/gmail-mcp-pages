Gmail MCP – Personal Integration

A private, single-user integration that connects one personal Gmail account to a locally running AI assistant (Bionic) through the Model Context Protocol (MCP).

Personal use only. This application is operated by and for a single individual — its owner. It is not distributed, not offered as a service, and has no other users.

What it does

  • Reads Gmail messages and threads on request
  • Searches the mailbox using standard Gmail search syntax
  • Formats message content for display
  • Marks messages as read
  • Handles attachments when asked

How it works

All processing happens locally on the owner's own computer. Access to Gmail is granted through Google OAuth 2.0 and limited to the scopes gmail.readonly and gmail.modify. Credentials are stored only on the owner's device.

Privacy

See the Privacy Policy for details on what data is accessed, how it is used and stored, and how the grant can be revoked.

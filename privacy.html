Privacy Policy

This policy describes how the personal Gmail MCP integration ("the Application") handles data.

1. Who operates the Application

The Application is operated by a single individual — its owner — strictly for personal use. There are no other users, and the Application is not offered, distributed or made available to third parties.

2. What data is accessed

  • Gmail data — messages, threads, headers, bodies, labels and attachments in the owner's own Gmail account, accessed only when the owner explicitly requests an action.
  • OAuth credentials — a refresh token issued by Google, stored locally on the owner's device.

3. How data is used

Gmail data is used solely to fulfil the owner's requests — for example reading, searching, formatting, or marking messages as read. All processing happens locally on the owner's computer.

4. Sharing and transfer to third parties

No Gmail data is transmitted to, stored on, or shared with any third party. The Application does not sell or transfer user data. Data is not used for advertising, and it is not used to train or improve machine-learning models other than the owner's own local assistant, which runs entirely on the owner's device.

5. Storage and retention

Gmail data is held in memory only for as long as is needed to answer a request, and is not retained afterwards. The only persistent item is the OAuth refresh token, stored locally on the owner's device.

6. Security

Communication with Google services uses HTTPS. Credentials are kept in local configuration on a single device and are not published.

7. Revoking access

The owner can revoke the Application's access to Gmail at any time at myaccount.google.com/permissions. Removing the local configuration deletes the stored token.

8. Google API Services User Data Policy

The Application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

9. Changes to this policy

Any changes to this policy will be published on this page together with an updated date.
